Arsenal Crafting a NeoForge Minecraft Mod for 1.21.1 (21.1.74)

Forge modular tools & weapons, upgrade armor using skill points, and wield gadgets.

Note: This 0.1 version was mostly vibe coded. I did this becuase I have not learned NeoForge yet (coming from Forge 1.18.2) and wanted to get a prototype built so we can attract members to the ArsenalCrafting Team.

What's been implemented so far:
right now alloy materials in their most basic form (bronze), Pickaxe Head, Tool  Rod (no binding yet), no textures as of now (data gen is planned), the tool station with gui, allows you to build your tool, augments (autosmelt, and oreminer works) and installing augments (consumes item now, will be changing)
