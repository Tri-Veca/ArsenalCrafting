Arsenal Crafting a NeoForge Minecraft Mod for 1.21.1 (21.1.74)

Note: Change to dev branch. Main is 200 commits behind Dev. Not merged yet

Forge modular tools & weapons, upgrade armor using skill points, and wield gadgets.

What's been implemented so far on Dev Branch: What we’ve already implemented: Data gen Tool components, Augments, Lang and Textures. Augments: Auto Smelt, Ore Miner, Fortune, Silk Touch, Light, Magnetism and Efficiency. Arsenal Pickaxe. Early version of Toolkit. Working. Lava tank. Materials. Assembly works, combining pickaxe head, core (binding) and tool rod. Tool Parts are hotswapable! Augment GUI for tools, enable / disable augs. Installing augments now works as intended, the tool stores the augments, toolkit displays them in the correct slots. An early version of the Repair Kit is working. Core power foundation, copper, tin, bronze, netherite, steel, gold, diamond (wip), iron, titanium added. WIP Alloy BE works with recipes. Mold (casts) blocks are in the game. Lava tank and Alloy Smelter blend into multiblock casings automatically. Placing Faucets onto casing blocks converts it into a “drain block” even though drain blocks don't exist, just updates block state.

Gravel now drops raw tin. Katana, dagger and Broadsword added as well as Knockback, Looting and Sharpness augments. Early Power is in; Fossil Gen is the only one that produces right now, discharging and charging with PowerBank and cables move power. Drill and Saw now work. JEI Integration works with Toolkit and WIP AlloySmelter (solid recipes and liquid mixing recipes), Alloy Fluids. Arsenal Commands make testing really easy. W.I.P Casting is in; you can place a mold in the casting station and pour out liquid, the mold then fills with a darkened item as it slowly brightens when done setting.

Blueprint Casting Table is in; you trade blueprint + gold/ bronze in for packages. Early Multiblock formation is in! Tiers and dynamic scrollable slots work in Alloy Smelter. You throw gravel into a lava source to get basic material. you can do a stack maximum. Once the event is over it makes the lava source air. Basic material is used in crafting Red crit particles now replace the vanilla crit system. Titanium Loop is in, decided to forgo the recycler for now!
